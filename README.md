# Crime Data Analysis in Malaysia
 This project performs crime data analysis of Malaysia by analyzing crime rates across different states and visualizing pervelance of crime by states. 

 ## Features
 - Crime Data Analysis
 - Data Visualization
 
 ## Installation & Setup
 1. Clone the repository
    ` git clone ** the url ** `
 2. Navigate to the project directory
 3. Install dependencies
 4. Ensure you have the crime data and population data CSV in the same directory
 5. Run the main file with this command
    ` python3 CrimeDataMsia.py `
